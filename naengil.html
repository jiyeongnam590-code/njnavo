USER PROBLEM / GOAL / SOLUTION

?

USER PROBLEM

  • 보유 재료를 잊고 방치해요.
  • 식사 메뉴를 정하는 데 시간이 걸려요.
  • 재료 관리가 체계적이지 않아요.
◎

GOAL

  • 보유 재료를 효율적으로 활용해요.
  • 상황에 맞는 메뉴를 빠르게 찾아요.
  • 식재료 낭비를 줄이고 더 건강하게 관리해요.
✦

SOLUTION DIRECTION

  • 냉장고 재료 기반 맞춤 추천
  • 간편한 조리와 재고 관리 경험 제공
  • 직관적이고 접근성 높은 UI/UX
